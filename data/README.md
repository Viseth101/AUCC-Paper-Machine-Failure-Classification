# Data

No raw data is committed to this repository.

The notebook downloads the **AI4I 2020 Predictive Maintenance Dataset** (`ai4i2020.csv`, 10,000 rows) automatically with [`kagglehub`](https://github.com/Kaggle/kagglehub) from the Kaggle dataset
[`stephanmatzka/predictive-maintenance-dataset-ai4i-2020`](https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020).
The dataset is also available from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset).

`kagglehub` caches the file locally (by default under `~/.cache/kagglehub`). Some environments ask for Kaggle credentials; see the kagglehub README.
